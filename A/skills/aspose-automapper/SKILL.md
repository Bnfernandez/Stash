# Aspose + AutoMapper

## Aspose

- Inspect how documents/PDFs are loaded, modified, flattened, saved, and returned before changing behavior.
- Preserve document fidelity, editable-versus-flattened semantics, streams, disposal, and output format.
- Avoid changing document processing libraries or versions unless requested.

## AutoMapper

- Inspect the existing profiles and mapping registration before adding mappings.
- Prefer explicit member configuration for fields where silent mapping could change persisted or user-visible behavior.
- When mapping models involved in contracts, verify null/default behavior.

## Verification

Prefer focused tests using representative documents/mappings. Verify output artifacts where practical.
